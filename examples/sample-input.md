v2.4.0 变更草稿（内部，供撰写发布说明）

产品：云端待办「清单侠」桌面客户端 2.4.0

新增
- 支持按周 / 按月创建重复任务；完成后自动生成下一次实例。
- 新增「日历」视图，可按月浏览截止日期。
- 导出支持 CSV，字段含标题、状态、截止时间（UTC）。

变更
- 截止日期统一按 UTC 存储，界面按系统本地时区显示。
- 设置页「提醒提前量」默认从 15 分钟改为 30 分钟（仅新安装；升级用户保持原值）。

修复
- 修复 Windows 下托盘图标在深色任务栏几乎不可见的问题。
- 修复含 emoji 的任务标题在搜索中匹配失败。

破坏性
- 移除公开 API `GET /v1/tasks?due=local`；请改用 `due_utc` 并自行换算时区。
- 配置文件 `~/.qingdanxia/config.json` 中 `remindMinutes` 改名为 `remind_minutes`；首次启动会自动改写一次，旧键不再读取。

已知问题
- 重复任务暂不支持「每周指定多个星期几」（例如每周二和周四）。
- 日历视图在宽度小于 800px 的窗口会裁切周末列。
- CSV 导出不含附件与评论。

- 内部消息队列主题名、监控项目 ID
- 竞品名称与对标结论
- 未发布的移动端路线图与下季度功能猜测
